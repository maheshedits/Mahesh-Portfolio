MAHESH VIDEO EDITOR PORTFOLIO

Files:
- index.html
- style.css
- script.js
- assets/ (add your thumbnails/videos here)

QUICK NETLIFY DEPLOY:
1. Create a GitHub repository named mahesh-portfolio.
2. Upload all files/folders from this project.
3. In Netlify: Add new project -> Import an existing project -> GitHub.
4. Select the repository.
5. Leave Build command empty and Publish directory as / (or the repository root).
6. Deploy.

BEFORE PUBLISHING:
- Replace your-email@example.com in index.html.
- Replace 91XXXXXXXXXX with your WhatsApp number.
- Replace the placeholder project visuals with your own thumbnails or video links.
- Update the experience text if needed.
